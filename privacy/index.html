개인정보 처리방침

시행일 및 최종 수정일: 2026년 9월 14일

1. 개요

Volibot은 Discord 서버 관리, 음악 재생 및 편의 기능을 제공하기 위해 서비스 운영에 필요한 최소한의 정보를 처리합니다. 본 방침은 처리되는 정보의 종류와 목적, 보관 및 삭제 기준을 설명합니다.

2. 처리할 수 있는 정보

  • Discord 식별 정보: 서버 ID, 사용자 ID, 역할 ID, 채널 ID, 서비스가 생성하거나 관리하는 메시지 ID
  • 서버 설정: 관리자 설정, 음악 채널, 로그 채널, 자동 음성방, 역할, 티켓 및 기타 서버별 기능 설정값
  • 음악 기능 정보: 검색어, 사용자가 입력한 미디어 링크, 곡 식별자와 제목 등 재생에 필요한 메타데이터, 대기열, 반복·볼륨·재생 상태, 신청자 ID
  • 운영 및 관리 정보: 명령 실행과 권한 확인에 필요한 역할·권한 정보, 관리자 메모 및 서비스 기능 수행 과정에서 생성되는 기록
  • 음성 상태 정보: 음성 채널 입장·퇴장 여부, 자동 음성방 소유자 및 기능 수행에 필요한 일시적인 상태
  • 이용자가 입력한 값: 방 이름, 모집 제목, 티켓·역할·관리 설정 등 명령 수행에 필요한 정보

Volibot은 음성 통화의 실제 오디오를 녹음하거나 저장하기 위한 기능을 제공하지 않습니다. 일반적인 기능 제공을 위해 Discord 메시지 내용을 지속적으로 수집·보관하는 것을 목적으로 하지 않습니다.

3. 이용 목적

  • 음악 검색, 재생, 대기열 및 재생 상태 관리
  • 자동 음성 채널 생성·관리 및 소유자 관리
  • 서버별 설정 저장, 복원 및 관리 기능 제공
  • 입장·퇴장 및 관리자 활동 기록
  • 티켓, 역할 자동화, 모집 및 기타 편의 기능 제공
  • 권한 확인, 오류 진단, 보안 유지 및 비정상적인 사용 방지

4. 보관 및 삭제

서버 설정, 자동 생성 채널 관련 메타데이터, 티켓·역할 설정, 음악 재생 상태 등 지속적인 기능 제공에 필요한 정보는 해당 기능을 제공하는 동안 보관될 수 있습니다. 검색·재생 과정의 일시적인 정보는 기능 수행 또는 장애 복구에 필요한 범위에서 처리되고 더 이상 필요하지 않으면 폐기됩니다.

서버 관리자가 관련 설정을 초기화하거나 Volibot을 서버에서 제거하면 일부 데이터가 삭제 또는 갱신될 수 있습니다. 이용 중단 후 남아 있는 데이터의 확인·삭제가 필요한 경우 아래 문의 방법을 통해 요청할 수 있습니다.

5. 외부 서비스 및 운영 인프라

Volibot은 기능 제공을 위해 Discord API 및 음악 검색·재생에 필요한 외부 미디어 서비스를 사용할 수 있으며, 서버·데이터베이스 등 운영 인프라 제공자가 서비스 운영에 필요한 범위에서 정보 처리에 관여할 수 있습니다. 각 외부 서비스에는 해당 서비스의 정책이 적용될 수 있습니다.

Volibot은 이용자의 개인정보를 판매하지 않습니다. 법적 의무가 있는 경우 관계 법령에 따라 정보가 제공될 수 있습니다.

6. 보안

운영자는 접근 권한 제한, 비밀정보 분리, 데이터베이스 접근 통제 등 합리적인 기술적·관리적 조치를 통해 처리 정보를 보호하도록 노력합니다. 다만 인터넷을 통한 정보 처리의 절대적인 보안을 보장할 수는 없습니다.

7. 이용자의 선택 및 삭제 요청

서버 관리자는 Volibot의 기능을 비활성화하거나 앱을 서버에서 제거할 수 있습니다. 본인 또는 관리 중인 서버와 관련된 저장 데이터의 확인·삭제가 필요한 경우 운영자에게 요청할 수 있으며, 대상 식별을 위해 Discord 사용자 ID 또는 서버 ID 확인을 요청할 수 있습니다.

8. 아동 및 청소년

Volibot은 Discord에서 허용되는 이용자를 대상으로 하며 별도로 아동의 개인정보를 수집하기 위한 서비스를 제공하지 않습니다. 이용자는 Discord의 연령 요건과 관련 정책을 준수해야 합니다.

9. 정책 변경

서비스 기능, 운영 방식 또는 관련 규정이 변경되는 경우 본 방침을 수정할 수 있으며, 변경 시 본 페이지의 최종 수정일을 갱신합니다.

10. 문의

개인정보 관련 문의 또는 삭제 요청은 Volibot 공식 Discord 서버에서 운영자에게 요청할 수 있습니다. 개인정보가 포함된 내용은 공개 채널에 직접 작성하지 마시고, 운영자가 안내하는 별도의 확인 방법을 이용해 주세요.
