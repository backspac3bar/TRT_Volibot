개인정보 처리방침

시행일 및 최종 수정일: 2026년 9월 11일

1. 개요

TRT Volibot은 Discord 서버 관리 및 편의 기능을 제공하기 위해 필요한 최소한의 정보를 처리합니다. 본 방침은 어떤 정보를 처리하고, 어떤 목적으로 사용하며, 어떻게 보관·삭제하는지 설명합니다.

2. 처리할 수 있는 정보

  • 서버 정보: 서버 ID, 서버별 기능 설정값
  • 채널 및 메시지 식별자: 채널 ID, 서비스가 생성하거나 관리하는 메시지 ID
  • 이용자 식별자: 사용자 ID, 자동 음성 채널 소유자 ID, 모집 기능의 주최자 및 참가자 ID
  • 권한 정보: 명령 실행 가능 여부를 확인하기 위한 서버 권한 및 역할 정보
  • 음성 상태 정보: 음성 채널 입장·퇴장 여부 및 기능 수행에 필요한 일시적인 상태
  • 이용자가 입력한 값: 방 이름, 모집 제목, 인원 제한, 관리자 설정 등 명령 수행에 필요한 정보

TRT Volibot의 일반적인 서버 관리 기능은 Discord의 일반 메시지 내용을 지속적으로 읽기 위한 Message Content 접근을 필요로 하지 않으며, 음성 통화의 실제 오디오 내용을 녹음하거나 저장하기 위한 목적으로 처리하지 않습니다.

3. 이용 목적

  • 자동 음성 채널 생성·관리 및 소유자 관리
  • 서버별 설정 저장 및 복원
  • 입장·퇴장 기록과 서버 관리 기능 제공
  • 선착순 모집 및 참여 상태 유지
  • 관리자 및 이용자의 권한 확인
  • 오류 진단, 보안 유지 및 비정상적인 사용 방지

4. 보관 및 삭제

서버 설정, 자동 생성 채널 관련 메타데이터, 모집 상태 등 지속적인 기능 제공에 필요한 정보는 해당 기능을 제공하는 동안 보관될 수 있습니다. 일시적인 상태 정보는 기능 수행에 필요한 기간 동안만 처리되고 더 이상 필요하지 않으면 폐기됩니다.

서버 관리자가 관련 설정을 초기화하거나 기능을 제거하면 해당 데이터의 일부가 삭제되거나 갱신될 수 있습니다. 서비스 이용을 중단한 뒤 남아 있는 데이터의 삭제를 원하는 경우 아래 문의 방법을 통해 요청할 수 있습니다.

5. 제3자 및 운영 인프라

TRT Volibot은 개인정보를 판매하지 않습니다. 서비스 운영 과정에서 Discord와 서버·데이터베이스 등 기술 인프라 제공자가 서비스 제공, 보안 및 운영에 필요한 범위에서 정보 처리에 관여할 수 있습니다. 법적 의무가 있는 경우 관계 법령에 따라 정보가 제공될 수 있습니다.

6. 보안

운영자는 접근 권한 제한, 비밀정보 분리, 데이터베이스 접근 통제 등 합리적인 기술적·관리적 조치를 사용해 처리 정보를 보호하도록 노력합니다. 다만 인터넷을 통한 정보 처리의 절대적인 보안을 보장할 수는 없습니다.

7. 이용자의 선택 및 삭제 요청

서버 관리자는 TRT Volibot을 서버에서 제거하거나 관련 기능을 비활성화할 수 있습니다. 본인 또는 관리 중인 서버와 관련된 저장 데이터의 확인·삭제가 필요한 경우 운영자에게 요청할 수 있으며, 대상 데이터 식별을 위해 Discord 사용자 ID 또는 서버 ID 확인을 요청할 수 있습니다.

8. 아동 및 청소년

TRT Volibot은 Discord에서 허용되는 이용자를 대상으로 하며, 별도로 아동의 개인정보를 수집하기 위한 서비스를 제공하지 않습니다. 이용자는 Discord의 연령 요건과 관련 정책을 준수해야 합니다.

9. 정책 변경

서비스 기능, 운영 방식 또는 관련 규정이 변경되는 경우 본 방침을 수정할 수 있으며, 변경 시 본 페이지의 최종 수정일을 갱신합니다.

10. 문의

개인정보 관련 문의 또는 삭제 요청은 운영자의 GitHub 프로필을 통해 연락할 수 있습니다.
