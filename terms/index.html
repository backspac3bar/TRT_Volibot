이용약관

시행일 및 최종 수정일: 2026년 9월 11일

1. 목적

본 약관은 Discord 애플리케이션 “TRT Volibot”(이하 “서비스”)의 이용 조건과 운영 기준을 정합니다.

2. 제공 기능

TRT Volibot은 Discord 서버 운영을 돕기 위해 다음과 같은 기능을 제공합니다.

  • 자동 음성 채널 생성 및 관리
  • 음성 채널 이름 및 인원 제한 변경
  • 음성 채널 입장·퇴장 관리 및 기록
  • 빠른 입·퇴장에 대한 서버 관리 기능
  • 서버별 관리자 설정 및 채널 설정
  • 선착순 모집 및 참여 관리
  • 기타 Discord 서버 운영 편의 기능

일부 기능은 서버 권한, Discord API 상태, 운영 환경 또는 기술적 사유에 따라 제한되거나 변경될 수 있습니다.

3. 이용자의 책임

  • 이용자는 Discord의 이용약관, 커뮤니티 가이드라인 및 관련 법령을 준수해야 합니다.
  • 서비스를 스팸, 괴롭힘, 권한 남용, 불법 행위 또는 타인의 권리를 침해하는 용도로 사용해서는 안 됩니다.
  • 서버 관리자는 TRT Volibot에 부여하는 권한과 서버 설정을 적절히 관리할 책임이 있습니다.

4. 서비스 변경 및 중단

서비스의 안정성, 보안, 유지보수, Discord API 변경 또는 운영상 필요에 따라 기능을 수정하거나 일시적으로 중단할 수 있습니다.

5. 이용 제한

서비스 안정성에 영향을 주는 비정상적 사용, 자동화된 남용, 과도한 요청, 권한 악용 또는 본 약관 위반이 확인되는 경우 특정 서버 또는 이용자의 서비스 이용을 제한할 수 있습니다.

6. 보증 및 책임

서비스는 가능한 범위에서 안정적으로 제공되지만, 중단·오류·데이터 손실이 전혀 발생하지 않음을 보장하지 않습니다. 관련 법령이 허용하는 범위에서 서비스 이용으로 발생한 간접적 또는 예측하기 어려운 손해에 대한 책임은 제한될 수 있습니다.

7. 개인정보

서비스가 처리하는 정보와 처리 목적, 보관 및 삭제에 관한 내용은 개인정보 처리방침에서 확인할 수 있습니다.

8. 약관 변경

기능, 운영 방식 또는 관련 규정이 변경되는 경우 본 약관을 수정할 수 있으며, 중요한 변경이 있을 경우 본 페이지의 최종 수정일을 갱신합니다.

9. 문의

서비스 또는 본 약관에 관한 문의는 운영자의 GitHub 프로필을 통해 연락할 수 있습니다.
